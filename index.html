Privacy Policy

Last updated: 7 October 2026 qr.digiseba.shop — Privacy Policy
QR BD is built around a simple promise: a customer’s document should exist only long enough to print, and nothing longer. This policy explains exactly what qr.digiseba.shop collects, how long a print file survives, and what a shop owner can see. We do not sell data to anyone, and we do not keep a library of your customers’ documents.
Saral bhasha meCustomer ki file sirf print hone tak rehti hai. Print hote hi wo delete ho jaati hai, aur kisi wajah se bachi hui har file usi raat 11:59 baje delete ho jaati hai. File ka koi backup nahi banta. Hum sirf job ka hisaab rakhte hain (pages, rakam, samay) — wo bhi har Sunday raat mit jaata hai. Card number ya UPI PIN hum kabhi nahi dekhte.

Customer files: zero retention

A customer’s print file is kept only until it is printed. It is never copied into a backup, never archived, and never opened or read by us.

  • As soon as the shop’s printer finishes the job, the file is deleted from our storage.
  • If a job fails or is cancelled, its file is deleted at the same moment.
  • If a job is not paid for within 60 minutes, its file is deleted.
  • A job that waits in the print queue for 24 hours without printing is closed, and its file is deleted.
  • Every night at 11:59 PM (India time), every customer file still in storage is deleted — printed or not, pending or stuck. No customer file is carried into the next day.
  • Every 10 minutes an automatic check also deletes any file older than 90 minutes that no running print job needs.
  • When a file is deleted, we also ask the storage network to clear any cached copy of it.

Because of this, a file cannot be recovered or reprinted from our side. Customers should keep their own copy of anything they send.

The file name is removed from the job record as soon as the job is printed, fails or is closed. Our server logs never contain a file’s name or content — only the job ID, file type and size.

On the shop’s computer

To print a job, the shop’s QR BD agent downloads the file into its own folder on the shop computer, sends it to the printer and deletes it straight after. Each time the agent starts, it empties that folder, so a file left behind by a power cut or a crash does not stay there.

From agent version 3.1, the agent’s log on the shop computer records only the job ID, file type and size — never the file name.

Windows may hold a short-lived copy in its print queue while the page prints. Shop owners should keep the printer setting “Keep printed documents” switched off.

What the shop owner can see

Each shop has its own dashboard on qr.digiseba.shop. It shows what happened to each job — job ID, time, pages, copies, colour, amount, payment status, and whether the file was printed and deleted — never the document itself. While a job is waiting, the shop can also see the file name so it can be matched at the counter.

One shop can never see another shop’s jobs or customers. The job list and its counts start again from zero after the clean-up every Sunday at 11:59 PM.

Apart from the file itself, we keep only the records the service needs. Each kind of record has a fixed time after which it is deleted automatically.

Backups

Customer files are never backed up. Our database is backed up every night so the service can recover from a failure. Those backups contain records only: before a backup is written, every file link and file name is removed from the print jobs. Backups are kept for 14 days and then deleted automatically.

A backup downloaded by the platform administrator also leaves out file links, file names, passwords and payment keys, and is deleted within 30 days.

Payment details are never stored with us

Online payments are handled by Razorpay or Cashfree — usually in the shop’s own account — or by the shop’s own UPI. Card numbers, CVV, UPI PIN and net-banking passwords are entered only on the payment provider’s secure screen. QR BD never sees or stores them. We receive only the transaction ID, the amount, and whether the payment succeeded.

Who processes data for us

We do not sell or rent personal data. These service providers handle data only to run QR BD:

  • Hostinger — our server and database, in Mumbai, India (print files for newer shop computers are kept here and deleted on the same schedule);
  • Cloudinary — holds print files only until they are deleted (its servers may be outside India);
  • Razorpay and Cashfree — online payments;
  • Brevo — account emails and alerts to shop owners;
  • Google Fonts, YouTube and Cloudflare — fonts, the demo video and page code your browser loads, and a bot check on some forms;
  • The shop you send a job to — it receives the print job and the counter details needed to hand it over;
  • Authorities — only when Indian law requires it.

Security

We use reasonable technical measures to protect qr.digiseba.shop, including encrypted connections, hashed passwords, admin access controls, and shop-level separation so no shop can reach another shop’s data. Immediate deletion of print files is itself a security measure — data that no longer exists cannot leak.

No system is perfectly secure, and we cannot promise absolute safety. Shop owners must protect their own Shop ID, password, and the computer running the print-relay agent.

Cookies and local storage

qr.digiseba.shop uses cookies and browser local storage to keep a shop owner signed in to the admin panel, remember the language chosen on the homepage, and record basic errors so faults can be fixed. These are functional. You can clear or block them in your browser, though the admin panel may then not stay logged in.

A random visitor ID is also kept in your browser to count visits. It does not contain your name or number.

What is QR BD?

QR BD is print-shop automation software for cyber cafes and print shops in Bangladesh. The customer scans the shop's QR code, uploads a document from their phone, pays, and the shop's printer prints it automatically — with no WhatsApp, no pen drive and no file transfer.

How does QR BD work, step by step?

In five steps: (1) the shop displays its QR code, (2) the customer scans it and opens the link in any phone browser, (3) the customer uploads a PDF or photo and picks black & white or colour, pages and copies, (4) the customer pays online or chooses pay-at-counter, (5) the shop's printer prints the job automatically.

Does the customer need to install an app?

No. The customer needs only a phone camera and a browser. There is nothing to download, no sign-up and no account.

Which printers are supported?

Any printer that is already installed on the shop's Windows PC — HP, Canon, Epson, Brother and others, inkjet or laser. A Wi-Fi printer is not required, because printing is done by the shop's PC, not by the phone.

Do I need a Wi-Fi printer or a special machine?

No. If your existing printer prints from your Windows PC today, it will work with QR BD. You only install a small print agent on that PC.

How much does QR BD cost?

There is a free demo first. After that plans start at ₹99 per month; yearly plans are ₹649 (Starter), ₹799 (Pro) and ₹999 (Premium); and there is a ₹1999 one-time Lifetime plan. There is no per-print commission and no hidden charge.

Who receives the customer's payment?

The shop owner receives it directly. Online payments go straight into the shop's own Razorpay or Cashfree account — QR BD does not hold or route the money and takes no cut per print.

Can customers still pay cash at the counter?

Yes. Each shop can allow online payment, pay-at-counter cash, or both. The shop decides.

Why is this better than receiving files on WhatsApp?

Because your personal number stays private, files do not get lost in chat, and printing does not need manual downloading. On WhatsApp you must find the file, open it and print it yourself; here the paid job prints automatically.

How long does setup take?

About two minutes to register the shop, plus a one-time install of the Windows print agent. After that the shop only needs to display its QR code.

Is it safe? What happens to the customer's file?

Files are stored temporarily only to complete the print job and are removed afterwards. Each shop sees only its own jobs. The full retention details are on the Privacy Policy page.

What happens if the internet goes off during a job?

Nothing is lost. Jobs stay safely in the queue, and when the connection returns the print agent picks them up and prints them automatically.

Can it print passport-size photos and resumes?

Yes. QR BD includes a 4×6 passport-photo layout tool and a resume maker, along with the normal document printing.

Who is QR BD for?

Cyber cafes, internet cafes, stationery and photocopy shops, DTP centres and print shops in India — any small shop that prints documents for walk-in customers.

Can I run QR BD under my own brand?

Yes. The white label programme lets a reseller run the same platform with their own brand name, logo, pricing and payment gateway. There is also an agent programme that pays commission for onboarding shops.

Is QR BD available across Bangladesh?

Yes. It works anywhere in India with a Windows PC, a printer and an internet connection. It is built and operated from Baliapur, Dhanbad, Jharkhand.

FAQ 🔒 Customer File Privacy

File upload ke baad, file kahaan store hoti hai?

Kahin nahi. File server par sirf print hone tak rehti hai — print command chalte hi turant delete command chal jaata hai, aur file permanently mit jaati hai.

Agar print cancel kar diya, to kya customer ko dobara upload karna padega?

Haan, dobara upload karna padega. Hamari policy hai ki koi file store nahi ki jaati — chahe print ho ya cancel. Ye aap khud verify kar sakte ho: System Tray me QR BD icon par right-click karke "📋 Logs Dekho" kholo, wahaan har file print ke turant baad delete hoti dikhegi.

Kisi bhi sawal ke liye kya karein?

Do tarike hain — (1) apne Shop Dashboard ke Support tab me WhatsApp Connect button se seedha message karo, ya (2) System Tray me icon par right-click karke "💬 Contact Admin" dabao. Dono se seedha admin tak baat pahunchti hai.
